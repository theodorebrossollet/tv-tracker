# Discover Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A full-screen swipe deck (sparkle icon in the Watching header) that mixes the owner's to-watch titles with TMDB recommendations seeded by titles rated 8+.

**Architecture:** One additive table (`DismissedSuggestion`); a pure ranking module and a DB-backed deck builder in `lib/discover.ts`; a pure swipe module in `lib/swipe.ts`; one new action module; a server-rendered `/discover` page with a client deck; a Settings reset row.

**Tech Stack:** Next.js 16 App Router, Prisma 7 on SQLite/Turso, vitest (real local SQLite from migrations, jsdom for components), TMDB.

**Spec:** `docs/superpowers/specs/2026-10-03-discover-design.md`

## Global Constraints

- Every Prisma call that touches per-user data carries `userId`; shared `Show`/`Movie` rows are never read as if per-user. A relation that is a list is always truthy (AGENTS.md).
- New actions follow `actions.ts`'s header: `requireOnboardedSession` above each `try`, every argument validated (`isTmdbMovieId` / `isTmdbShowId` for ids), returns `ActionResult`.
- Server state through `useOptimistic`; client-only state and ERROR MESSAGES in `useState` (an error in `useOptimistic` vanishes when the action settles). Server components never read plain values from `"use client"` modules.
- Swiping left never changes a title's real status; the movie `not_interested` status is NOT reused.
- Seeds: rated >= 8, at most 10, newest rated first; fewer than 3 seeds = no recommendations. Vote floor 100. At most 2000 dismissed rows per account.
- "Under 2h" = movies with runtime < 120 only; shows are excluded while it is on.
- One additive migration, one `CREATE TABLE` (+ its indexes), applied by the owner by hand before merging. The implementer never touches Turso.
- Sentence-case UI copy, no emoji. Dates via `components/watched-date.tsx` if any are shown.
- Commits end with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.

## Review Focus

- A recommendation already tracked (any status), on any of the caller's lists, or dismissed must never appear; another account's tracks/dismissals must not hide it. Pinned in Task 4.
- TMDB down or slow during deck load: the page still renders the owner's own titles with a quiet note, never an error page. Pinned in Task 4.
- Fewer than 3 seeds (including titles rated 7, an unrated watched title, and shows with no rated episodes): no recommendations, note shown. Pinned in Tasks 3 and 4.
- A swipe that is mostly vertical is scrolling the card, never a dismissal; a double-tap on ✕ must not dismiss two cards. Pinned in Tasks 5 and 7.
- A failed add or dismiss keeps its error visible after the action settles and does not advance the deck. Pinned in Task 7.
